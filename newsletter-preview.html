Comment utiliser ce modèle dans Brevo ?

  1. Cliquez sur le bouton violet ci-dessus « Copier le code HTML pour Brevo ».
  2. Rendez-vous dans votre compte Brevo > menu Campagnes > E-mail > Créer une campagne.
  3. Renseignez le nom de la campagne, l'expéditeur (ex: PassageS <passages26@mimesis-asso.fr>) et l'objet (ex: Lancement du dispositif PassageS en Drôme-Ardèche).
  4. À l'étape Conception, choisissez l'onglet « Coder votre propre modèle » puis « Utiliser l'éditeur HTML » ou « Coller le code ».
  5. Collez simplement le code HTML copié (Ctrl+V ou Cmd+V) et enregistrez.
  6. Envoyez un e-mail de test (BAT) sur votre boîte personnelle pour admirer le rendu parfait sur votre messagerie avant l'envoi officiel !
💡 Balises Brevo intégrées : Le modèle intègre déjà la balise {{ mirror }} (lien pour afficher dans le navigateur) en haut et la balise obligatoire {{ unsubscribe }} (lien de désinscription) dans le pied de page, assurant une conformité totale avec les filtres anti-spam et les règles RGPD de Brevo.
